# TODO — 多轨编辑器「专业效果器」风格 FX 面板

> 参考视觉：Cubase **Squasher**（深色机架 + 分组框 + 彩色标题条 + 旋钮 + 垂直推子 + 电平表）
> 范围：**只改每轨的「音质 + 音效」区**；轨道头、波形、transport、其他卡片不动
> 后端：**不改**（无新参数，仅换控件形态 + 加可视化，音频链路语义完全一致）

---

## 一、目标

把现在每轨的两行 `[label] + 横排滑块/步进器` 换成一张**专业插件面板**：

1. 控件形态 —— **旋钮**（连续比例量）+ **垂直推子**（时间/强度类）
2. 面板结构 —— 深色面板底 + 模块分组框 + 彩色标题条
3. 专业元素 —— 输入/输出电平表、压缩增益衰减表（GR）、EQ 频响曲线、参数数值徽标 + 双击复位
4. 排版 —— 模块对齐、间距统一，不堆砌

---

## 二、参数 → 控件映射

| 参数 | 范围 | 控件 | 所属模块 |
|---|---|---|---|
| `pan` 声像 | -1 … 1 | 旋钮 | 音质 |
| `eqLow` 低频 | -15 … 15 dB | 旋钮 | 音质 |
| `eqMid` 中频 | -15 … 15 dB | 旋钮 | 音质 |
| `eqHigh` 高频 | -15 … 15 dB | 旋钮 | 音质 |
| `hpf` 高通 | 0 … 2000 Hz | 旋钮 | 音质 |
| `lpf` 低通 | 0 … 20000 Hz | 旋钮 | 音质 |
| `compTh` 阈值 | -60 … 0 dB | 旋钮 | 动态 |
| `compRatio` 比率 | 1 … 20 | 旋钮 | 动态 |
| `echoDelay` 延迟 | 0 … 2000 ms | 垂直推子 | 回声 |
| `echoFb` 反馈 | 0 … 0.95 | 垂直推子 | 回声 |
| `echoMix` 混合 | 0 … 1 | 垂直推子 | 回声 |

> 中性默认值不变（声像 0 / EQ 0 / 高通 0 / 低通 0 / 阈值 0 / 比率 1 / 延迟·反馈·混合 0）。

## 三、面板布局（ASCII 稿）

```
┌────┬─ 音质 ───────────────────────────┬─ 动态 ──────┬─ 回声 ──────┬────┐
│IN  │ ┌──────────────┐  ◉    ◉    ◉    │      ◉      │  ▮   ▮   ▮  │OUT │
│电平│ │  EQ 频响曲线  │ 低频 中频 高频   │   ┌──┐      │ 延迟 反馈 混合│电平│
│表  │ │   (可拖手柄)  │  ◉    ◉    ◉    │   │GR│  ◉   │             │表  │
│    │ └──────────────┘ 高通 低通 声像   │   └──┘ 比率  │             │    │
└────┴──────────────────────────────────┴─────────────┴─────────────┴────┘
```

- **IN/OUT 电平表**：左右两端窄列，立体声双条，与推子同高
- **音质**：左侧频响曲线（180×84），右侧 6 个旋钮（2 行 × 3 列）
- **动态**：阈值/比率 2 个旋钮 + GR 表（垂直，顶部向下填充）
- **回声**：3 个垂直推子

窄屏（容器 < 780px）折行为 2 列 / 1 列，模块不压缩变形。

## 五、交互规格

**旋钮**
- 上下拖拽调值：整行程灵敏度 180px（拖满全范围）
- `Shift` + 拖拽 = 1/5 灵敏度（精调）
- 滚轮 = 1 档 step；双击 = 复位中性值
- 悬停显示参数名 + 当前值（`title`）
- 键盘：聚焦后 ↑/↓ 按 step 增减（沿用原生 number 语义）

**垂直推子**
- 拖拽 thumb 或点击轨道跳转；滚轮 1 档；双击复位

**实现要点（关键）**
- 旋钮与推子**底层仍是原生 `<input type="number">`**（透明覆盖在皮肤上），
  因此 `el.value` 读值、`input/change` 事件、工程回灌逻辑全部**零改动兼容**
- 皮肤用 SVG（旋钮）/ CSS 渐变（推子）；数值徽标由统一的 `syncFx(el)` 刷新，
  `applyTrackState` 里把 `el.value = x` 改为 `setFx(el, x)`（内部设值 + 刷视觉）
- `tabIndex`/焦点策略沿用现状（空格仍是全局播放热键）

**电平表 / GR 表**
- 在 `setupTrack` 链路插入两个 `AnalyserNode`：
  `src → env → [IN表] → fx.head … fx.tail → 轨增益 → [OUT表] → master`
- 电平用 `getFloatTimeDomainData` 求峰值，做 300ms 衰减平滑 + 峰值保持
- GR 直接读 `comp.reduction.value`（只读 AudioParam，Chrome 原生支持）
- 统一在现有 `rAF` 播放循环里更新；未播放时电平归零、GR 归零

**EQ 频响曲线**
- 用 `OfflineAudioContext` 造 5 个 biquad（hpf/lpf/low/mid/high），
  对 20Hz…20kHz 对数采样点调用 `getFrequencyResponse`，叠加后转 dB 绘制
- 频率点与后端一致（EQ 200/1000/4000，Q=1；滤波 Q=0.7071，12dB/oct）
- 3 个手柄（低/中/高）**可上下拖拽改 gain**（与旋钮双向联动）；频率固定（后端未暴露）

## 七、风险与取舍

| 风险 | 应对 |
|---|---|
| 面板高度增加（每轨约 +60px） | 控制旋钮尺寸与模块高度；必要时曲线缩到 160×72 |
| 窄容器（Gradio Tab 内嵌）折行 | 容器查询 / media query 折成 2 列或 1 列 |
| 拖拽与空格全局热键冲突 | 旋钮/推子用 pointer 事件，不占焦点；`preventDefault` 拦截拖拽期默认行为 |
| 电平表增加 CPU | 只在播放中更新；analyser 缓冲 1024，两条表共用一次读取 |
| 明暗主题下专业面板观感 | 面板色单独用 `--panel`/`--panel-line` 变量，两套主题各调一次 |
