## 0. 背景与目标

### 0.1 背景

第一阶段已定位并修复 6 项音质损失（详见"1. 现状基线"）。修复后客观指标已对齐源曲，
但**主观听感仍有"电子音/金属感"**，本方案针对该残余问题。

### 0.2 关键前提（已核实）

| 事实 | 来源 | 结论 |
|---|---|---|
| `seed-uvit-whisper-base_f0_44k` 是官方唯一的 SVC（歌声）模型 | `seed-vc/README.md` 模型表 | 模型选型正确，无需更换 |
| V2 `hubert-bsqvae-small` 为 22050Hz + 语音/口音定位 | 同上 | **不适合歌声，排除** |
| 官方 SVC 演示使用 100 扩散步 | seed-vc HF Space SVC 示例行 | 步数是最直接可调项 |
| `auto-f0-adjust` 官方明确"歌声转换一般不用" | `seed-vc/README.md` | **不开启** |
| 微调数据集只需音频（1~30s，单说话人，无需转写） | `seed-vc/data/ft_dataset.py` | few-shot 微调门槛低 |
| 官方称微调最小 1 条语音、100 步、T4 约 2 分钟 | `seed-vc/README.md` | 收益大、成本可控 |

### 0.3 本阶段目标

从"电平/结构正确"提升到"听感自然、电音感可接受"。

### 0.4 完成标准（可验证）

| 类型 | 指标 | 判定 |
|---|---|---|
| 客观 | 翻唱成品与源曲的 >10kHz 分带能量占比差 | ≤ 1.5 dB（当前待测基线） |
| 客观 | 积分响度与源曲差 | ≤ 1.0 LU（P1 已达 -14.1 vs -14.0） |
| 客观 | F0 相关系数（换嗓前后） | 不低于基线 |
| 客观 | DNSMOS OVRL/SIG/BAK（seed-vc 自带 onnx） | 各变体间相对比较 |
| 主观 | A/B 盲听 | 用户判定"电音感明显减轻" |

## 2. 残余根因假设与验证方式

| # | 假设 | 验证手段 | 归属阶段 |
|---|---|---|---|
| H1 | BigVGAN 44kHz 声码器高频过度生成，产生"亮/金属"质感 | 测 >8k/>10k/>12k 分带能量占比 vs 源人声 | P0 量化 + P2 |
| H2 | 扩散步数 40 不足（官方 SVC 演示用 100） | 40/60/100 单变量盲听 + 指标 | P1 |
| H3 | `inference-cfg-rate` 0.7 偏高，过拟合参考音色致金属化 | 0.5/0.7/0.9 扫描 | P1 |
| H4 | 参考干声短（10s）使每块仅约 20s，整曲切 9+ 块拼接 | 6/8/10s 扫描 | P1 |
| H5 | 参考音色本身带 Demucs 伪影（零样本只能复制"通用音色"） | few-shot 微调前后 A/B | P3 |
| H6 | 源人声分离残留串音/频谱空洞被换嗓放大 | UVR5/MDX 二次净化对比 | P4 |
| H7 | 混音链无修形（仅 loudnorm+amix）；原假设「合成高频无抑制」**已被 P1 推翻**（实为高频细节退化/over-smoothing） | D2'（高频细节补偿）对比 | P2 |
| H8 | 换嗓环节压缩动态（LRA 显著下降），导致听感"发干/电" | 轨级 A/B 测换嗓人声 LRA vs 源人声 | P0 量化 + P3 |

**原则**：先量化（P0）再动手，避免"凭感觉调参"。

**P0 首轮实测结论（2026-09-26，已推翻 H1）**：

| 指标 | 源曲 var1.wav | 成品 cover.flac | 差 |
|---|---|---|---|
| 积分响度 | -14.0 LUFS | -14.1 LUFS | -0.1 |
| 真峰值 | -0.7 dBTP | -0.4 dBTP | +0.3 |
| LRA | 8.2 LU | 6.6 LU | -1.6 |
| 谱质心 | 2450 Hz | 2641 Hz | +191 |
| >8k / >10k / >12k | -23.4 / -25.9 / -28.6 dB | -22.9 / -25.5 / -28.4 dB | +0.2 ~ +0.5 |

混音级分带差仅 +0.2~+0.5 dB，**远低于 1.5 dB 判据 → H1 在混音级不成立**，
P2 的 D2 高频搁架有过度修正风险，建议搁置（待确认）。

轨级 A/B（换嗓人声 vs 源人声，同为 256.3s 同源分离）：

| 指标 | 源人声 stem | 换嗓输出（Seed-VC 原始） | 差 |
|---|---|---|---|
| 谱质心 | 3904 Hz | 3610 Hz | -294 |
| 谱平坦度 | 0.197 | 0.106 | -0.09（更不噪声） |
| >10k 分带占比 | -22.2 dB | -21.5 dB | +0.69（OK） |
| LRA | 10.1 LU | 6.4 LU | **-3.7 LU** |
| 峰值 | -3.7 dBFS | 0.0 dBFS（真峰值 +0.15 dBTP） | 换嗓输出自身顶到 0dB |

两点重要口径修正：

1. 落盘的 `<prefix>_converted_vocals.wav` 是 **Seed-VC 原始输出**，`loudnorm` 只在混音
   滤镜链内部执行、不落盘；因此"换嗓人声 LUFS +4.7"是口径差异，非真实问题。
   频谱类指标（质心/平坦度/分带占比）与电平无关，判据仍然成立。
2. `seed-vc/inference.py` 在 `torchaudio.save` 前**无任何归一或限幅**，输出峰值可达 1.0，
   属第三方侧行为；混音链 `loudnorm` + `alimiter` 已兜底，暂不改第三方源码。

**新增首要怀疑对象 H8（LRA -3.7 LU 动态压缩）**：轨级唯一硬退化，需在 P1/P2 后重点复核。

## 3. 阶段划分

### P0 · 量化脚手架（必须先做，零依赖）

**产出**：`yue2-webui/tools/audio_ab_report.py`（单文件，仅 stdlib + 系统 ffmpeg）

**功能**：输入任意个音频路径，输出指标表（CSV，UTF-8 + BOM）

- 积分响度 LUFS、真峰值、LRA（复用 `loudnorm`）
- 谱质心（Hz）
- 分带能量占比：>8k / >10k / >12k 相对全带（dB）
- 总时长与削波计数

**目的**：为 P1~P4 的每个变体提供同一把"尺子"，让"电音感"从主观变可比较。

**验证**：对存量 `outputs/quality_test_cover/qt_cover.flac` 跑通并输出合理数值。

**风险**：低（只读，不写产物）。

### P2 · 前端 DSP 修形（零新依赖，ffmpeg）

> **方向修正（2026-09-26，基于 P1 实测）**：原方案假定换嗓"高频过度生成"，据此设计的
> D2「高频搁架压制」方向错误——P1 实测换嗓后高频不升反降（谱滚降 6800~7900Hz vs 源
> 8950，谱平坦度 0.10 vs 源 0.197），真实问题是 **over-smoothing（高频细节被抹平）**。
> D2 因此改为反向的**高频细节补偿**，其余项保留待评估。

| 编号 | 手段 | 滤镜 | 目的 | 状态 |
|---|---|---|---|---|
| D1 | 去齿音 | `deesser` | 抑制合成咝声 | 待评估（激励后齿音可能被放大，届时再定） |
| D2'（原 D2 反转） | 高频细节补偿 | `aexciter=amount=X:freq=7500` | 谐波激励，补偿 over-smoothing 抹掉的高频非谐波细节 | ✅ 已实施，3 档扫描中 |
| D3 | 源高频补偿 | `[conv]lowpass=f=8000` 与 `[src]highpass=f=8000` 加权混合 | 用**真实源高频**替换合成高频（SYKI-SVC 论文思路，SVCC 高分方案） | 待评估（优先级低于 D2'） |

**实现位置**：`worker.py` 混音 `filter_complex` 中换嗓人声分支 `a0_chain`，新增参数 `hf_enhance`（0~4，0=关）。
接线细节：`aexciter` 挂在 **loudnorm 之前**（`aresample=48000,pan=stereo,hf,loudnorm,aresample`），
激励抬高峰值后由 loudnorm 重新测量并归一，仍保证 TP=-1.5dB——若挂在 loudnorm 之后会让其 TP 承诺失效、
可能引入新削波，故不采用。

**接口贯通（已实施）**：
- `worker.py`：`_convert(..., cfg_rate=0.9, ref_sec=10.0, hf_enhance=0.0)`；`/api/convert` 解析
  `hf_enhance`（钳制 0~4），并把 `cfg_rate` 默认值 0.7→0.9
- `voice_client.py`：`convert(..., cfg_rate=0.9, hf_enhance=0.0)`，payload 透传 + 钳制
- `tools/cover_ab.py`：`--hf-enhance`，`--cfg` 默认改 0.9
- 单测：`tests/test_voice_client.py::test_convert_passes_quality_params` 覆盖三参数透传/钳制/默认值

**cfg 0.9 采纳为新默认（2026-09-26 用户确认）**：P1 实测 cfg 0.9 谱质心 3802Hz 最贴源人声
（0.5→3522 / 0.7→3610），已作为 `worker.py`/`voice_client.py`/`cover_ab.py` 的默认值。

**验证**：轨级（`audio_ab_report.py --ref 源人声`）看谱滚降/谱平坦度是否向源靠拢 + 混音级指标 + 盲听。

**风险与对策**：
- `aexciter` 过度 → 齿音/咝声被放大、听感发刺 → 扫描 0.5 / 1.0 / 2.0 三档，取听感与指标平衡点
- D3 会引入源分离伪影 → 先单独试，权重从 0.3 起

**回滚**：`hf_enhance` 默认 0，等于完全保持原有链路行为（已由单测锁定）。

#### P3 执行结论（2026-09-26）：❌ 判定无效，已回退

**执行过程**（GPU 独占，训练完即释放）：

| 项 | 结果 |
|---|---|
| 素材 | K歌之王人声切 17 段（5.88~12s，合计 183s），脚本 `tools/ft_prep_segments.py` |
| 缺失权重下载 | `OpenVoiceV2/converter/checkpoint.pth`(125MB)、`Plachta/Seed-VC/se_db.pt`(98MB) → 预取到 `seed-vc/checkpoints` |
| 训练起点 | `--pretrained-ckpt` 指向本地已有 DiT v2 权重（782MB），省掉一次下载 |
| 100 步档 | ✅ 82s 完成 → `runs/cover_kkzw_ft/ft_model.pth` |
| 50 步档 | 中间存档 `DiT_epoch_00002_step_00050.pth`（用于趋势判断） |
| 300 步档 | ❌ **发散**（loss 自 120 步起 NaN），权重与目录已删除 |

**训练不稳定性（关键发现）**：`train.py` 内 `scheduler_params.base_lr` 硬编码 **1e-5**，
对 17 条小数据偏高 —— 100 步档 loss 已从 0.523 **单调升到 0.586**（发散前兆），
300 步档直接 NaN。若后续重启微调评估，第一步应是**降 lr（2e-6 量级）**，而非加步数。

**A/B 实测**（源曲 `漠河小猫 var1`、参考 K歌之王人声，steps 40 / cfg 0.9 / ref 10s，仅换权重）：

| 指标 | 源人声 | 基线（官方权重） | FT 50 步 | FT 100 步 |
|---|---|---|---|---|
| 谱平坦度 | 0.197 | 0.110 | 0.116 | 0.157 |
| LRA LU | 10.1 | 6.5 | 5.7 | 7.2 |
| 谱质心 Hz | 3904 | 3862 | 4083 | 4645 |
| 谱滚降 Hz | 8950 | 7969 | 8793 | 9790 |
| 削波代理 flat/peak | — | 0.79 / 21 | 5.20 / 342 | 6.61 / 156 |

**结论**：100 步档在 over-smoothing（谱平坦度 0.110→0.157）与动态压缩（LRA 6.5→7.2）
两项有客观改善，但高频能量上冲（谱质心 +741Hz、谱滚降超过源）+ 削波计数上升；
50 步档几乎无改善且 LRA 更差。**用户盲听后判定"微调无效"，本阶段终止。**

**回退范围**：`worker.py` / `src/voice_client.py` / `tools/cover_ab.py` /
`tests/test_voice_client.py` 中的 `ft_checkpoint` / `ft_config` 透传与绑定改动
**已全部回退**（`py_compile` + 107 项单测通过，全仓无 `ft_*` 残留引用）；
`tools/ft_prep_segments.py` 按要求保留。产物 `outputs/ab_test/P3_{base,ft,ft50}/`
保留作证据。

### P4 · 第三方组件（仅当 P1~P3 未达标，需下载）

| 组件 | 体积 | 定位 | 接入点 | 适配风险 |
|---|---|---|---|---|
| DeepFilterNet3 | ~2MB | 语音降噪（去咝声/底噪） | 换嗓后、混音前 | 低，可能削气声 |
| UVR5 / MDX-Net | ~100MB | 二次人声净化 | 分离后、换嗓前 | 中，可能更"干" |
| Resemble Enhance | ~1GB | 扩散式语音增强 | 换嗓后 | **高**，语音向易削颤音/高频泛音 |

**说明**：语音增强模型以"去噪去混响、提清晰度"为优化目标，**不针对合成伪影**，
用在歌声上常伴随颤音/气声被削，收益不确定。

**前置**：需用户明确批准后方可下载（外部网络 + 依赖安装）。

#### 3.5 P5 · 参考干声质量与参考段选择（2026-09-27，P5C 已产线化）

**方案 A · 换分离算法净化参考/源人声（判定不接入）**：用 `audio-separator` 的 MDX

谱平坦度反超源曲但风险最高；用户盲听选 **B2**（MDX 人声 + Demucs 伴奏）。
跨曲复现（《千千阙歌》）B2 串音更少，但 MDX 人声高频过亮（质心 5201Hz、平坦度 0.248）
且电平比 Demucs 低 2.7 LU → 成品响度低 1.3 LU，需额外响度补偿。
**结论：B2 不接入产线（收益不足以承担额外依赖与响度补偿链路）。**

**方案 C · 参考段选择（判定有效，已产线化）**：把参考干声的裁剪段从"整曲能量最高
10s"改为"人声主导度最高 10s"（人声 RMS − 配对伴奏 RMS，即伴奏串音最少段）。
K歌之王实测（cfg 0.9 / 10s / hf_enhance 0）：换嗓产物谱质心偏差 +1425Hz → **+509Hz**、
换嗓人声 LRA 6.8 → **9.5 LU**、成品真峰值 +1.40 → **+0.13 dBTP**——是唯一同时改善
动态与频谱过冲的方案。用户盲听"效果还可以"，故产线化。

**产线化形态**：翻唱 Tab 新增「参考段」下拉（默认「智能 (推荐)」= P5C 最优参数）：
- `smart`：参考干声来自**分离记录**时用同一次分离的伴奏轨算人声主导度挑段；上传干声 /
  音色库无配对轨 → 自动回退 `energy`（旧行为），保证默认不劣化。
- `energy`：能量最高段（旧行为）。
- `full`：整曲不裁剪（等价关闭本优化）。

> 附：曾尝试用自包含特征（谱平坦度 / 谐噪比 / >8k 占比 / 与伴奏相干度）自动定位该段，
> 实测 4 个特征全部排名靠后（真值段是全曲能量偏低、伴奏几乎消失的段落），故不做猜测，
> 仅在能拿到配对伴奏时启用主导度口径。
